# 展示材料

公开截图均运行 `python tools/capture_public_gui.py` 捕获：PySide6 实际窗口、原创公开火柴人、空的临时 SQLite 数据库；没有读取私人动画或伪造新闻、赛事数据。

建议 README 展示顺序：

1. [番茄钟与完整桌宠结构](screenshots/public-pomodoro.png)——首图，展示角色、轮胎、面板。
2. [To-Do](screenshots/public-todo.png)——展示四象限布局与输入。
3. [新闻](screenshots/public-news.png)——当前为空缓存状态；拍摄视频时可用实际刷新得到的公开新闻，不应把示例数据当实时内容。

60–90 秒演示视频建议：先展示角色行走和拖动（10–15 秒），依次点开五个轮胎并展示赛历/赛果的**实时或明确标注的缓存内容**（20–25 秒），展示新闻刷新动画、原文与反馈（15–20 秒），添加并完成一条临时任务（10 秒），最后开始、暂停番茄钟并关闭窗口（10–15 秒）。网络或本地模型不可用时，单独说明该段验证条件，无需把所有功能压进同一镜头。录制前检查桌面通知与用户数据库中的个人信息。
